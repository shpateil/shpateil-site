# shpateil site

исходники [shpateil.fun](https://shpateil.fun). тёмная страница с контактами и глитч эффектами
html css javascript и express. без сборщика. контент и результаты игры хранятся в json

## запуск

нужен node.js 22 или новее

```sh
npm ci
cp .env.example .env
# заполни SHPATEIL_ADMIN_PASSWORD случайным паролем от 16 символов
node --env-file=.env api/server.js
```

открыть http://127.0.0.1:3000

## что внутри

`index.html` главная страница
`css/` и `js/` оформление игра и админка
`api/server.js` настройки контент и таблица результатов
`static/` локальные шрифты

боевые настройки аналитика и данные посетителей не включены. публичные ссылки на автора сохранены. перед использованием как своего сайта замени контакты и метаданные

аналитика выключена по умолчанию. ENABLE_ANALYTICS=1 включает сбор ip и параметров посещения. TRUST_PROXY=1 нужен только за доверенным локальным reverse proxy который переписывает forwarded заголовки. запускать один процесс node и использовать https на reverse proxy

это публикация исходников без полного регрессионного прогона. таблица игры доверяет результатам клиента и не предназначена для соревнований с призами
